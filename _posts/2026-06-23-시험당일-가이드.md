# 기말고사 당일 채점용 가이드 (시험당일.py)

시험 당일에 `best_model.pkl`과 `selected_features.pkl` 파일이 성공적으로 만들어졌다면, 이제 실제 평가용 데이터(`test.csv`)를 불러와서 정답을 맞혀볼 차례입니다.

아래 코드를 복사해서 실행하시면 **모델이 예측한 정답 배열**과 **F1 Score 점수표(Classification Report)**를 바로 확인하실 수 있습니다.

---

### 📥 평가 및 점수 확인용 전체 코드

```python
import pandas as pd
import joblib
from sklearn.metrics import classification_report

# ---------------------------------------------------------
# 1. 저장된 최고 성능 모델 불러오기
# ---------------------------------------------------------
model = joblib.load("best_model.pkl")

# ---------------------------------------------------------
# 2. 학습 때 사용했던 핵심 Feature 목록 불러오기
# ---------------------------------------------------------
features = joblib.load("selected_features.pkl")

# ---------------------------------------------------------
# 3. 시험 당일에 주어지는 평가용 데이터(test.csv) 읽기
# ---------------------------------------------------------
# ※ 만약 시험 당일 주어지는 파일 이름이 다르다면 이 부분을 수정하세요!
test_df = pd.read_csv("test.csv")

# ---------------------------------------------------------
# 4. Feature 추출 (학습 때 사용한 피처만 똑같이 뽑아내기)
# ---------------------------------------------------------
X_test = test_df[features]

# ---------------------------------------------------------
# 5. 모델을 통해 정답 자동으로 예측하기
# ---------------------------------------------------------
pred = model.predict(X_test)

print("\n===== 예측 결과 =====")
print(pred)

# ---------------------------------------------------------
# 6. target이 있는 경우 실제 점수(F1) 평가하기
# ---------------------------------------------------------
# ※ 시험 데이터에 정답(target)이 포함되어 있다면 아래 코드가 실행되어 점수를 보여줍니다.
if "target" in test_df.columns:
    y_test = test_df["target"]
    
    print("\n===== Classification Report =====")
    print(classification_report(y_test, pred))
```

### 💡 주의사항 (Troubleshooting)

1. **파일을 찾을 수 없다는 에러가 날 때**
   * 에러 메시지: `FileNotFoundError: No such file or directory: 'best_model.pkl'`
   * 해결: 먼저 모델을 생성하는 학습 코드를 실행하여 `.pkl` 파일 두 개가 폴더에 정상적으로 만들어졌는지 확인하세요.
2. **평가용 데이터 파일 이름이 다를 때**
   * 해결: `pd.read_csv("test.csv")` 부분의 `"test.csv"`를 실제 시험에서 제공받은 파일 이름(예: `"exam_data.csv"`)으로 바꿔주세요.
