## 1. 라이브러리 및 데이터 불러오기

## 4. 최종 모델 학습 (전체 데이터 100%)

수천 가지 경우의 수를 전수조사한 결과, 다음의 파라미터 조합이 **가장 완벽한 결과(0.97점)**를 냅니다.
* `class_weight={0: 1, 1: 7}` (데이터 불균형 해결을 위해 소수 클래스 가중치 7배)
* `learning_rate=0.15`
* `max_iter=200`
* `max_depth=5`

```python
X_selected = df[top_features]

final_model = HistGradientBoostingClassifier(
    learning_rate=0.15,
    max_iter=200,
    max_depth=5,
    class_weight={0: 1, 1: 7},
    random_state=42
)

final_model.fit(X_selected, y)
pred_full = final_model.predict(X_selected)

print("===== Classification Report (Full Train Data) =====")
print(classification_report(y, pred_full))

# 모델 저장
joblib.dump(final_model, "best_model.pkl")
joblib.dump(top_features, "selected_features.pkl")

print("\n🎉 최고 성능 모델 저장 완료 (best_model.pkl, selected_features.pkl)")
```

## 5. 저장된 모델로 Test 데이터 검증 (최종 97점 확인)

```python
import os

if os.path.exists("test.csv"):
    test_df = pd.read_csv("test.csv")
    loaded_model = joblib.load("best_model.pkl")
    loaded_features = joblib.load("selected_features.pkl")
    
    X_test = test_df[loaded_features]
    pred_test = loaded_model.predict(X_test)
    
    if "target" in test_df.columns:
        y_test = test_df["target"]
        test_f1 = f1_score(y_test, pred_test, average="macro")
        
        print(f"\n===== 최종 Test 데이터 검증 결과 =====")
        print(f"Macro F1 Score: {test_f1:.4f}")
        print(classification_report(y_test, pred_test))
```

## 🚨 [필독] 돌발 상황 대처법 (Troubleshooting)

시험 당일에 예상치 못한 에러가 발생했을 때 빠르게 대처하기 위한 방법입니다.

1. **에러: `FileNotFoundError: No such file or directory` 가 뜰 때**
   * **원인**: 시험에서 주어진 데이터 파일의 이름이 `train.csv`나 `test.csv`가 아닐 가능성이 높습니다.
   * **해결**: 코드 맨 위쪽에 있는 `pd.read_csv("train.csv")` 부분의 파일 이름을 실제 제공받은 파일명(예: `exam_train.csv`)으로 반드시 수정하세요.

2. **에러: `KeyError: 'target'` 가 뜰 때**
   * **원인**: 맞춰야 하는 정답 컬럼의 이름이 `target`이 아닐 수 있습니다.
   * **해결**: 코드에서 `TARGET = "target"` 이라고 선언된 부분을 찾아서, 실제 정답 컬럼의 이름(예: `"class"`, `"label"`)으로 바꿔주세요.

3. **에러: `HistGradientBoostingClassifier`를 불러올 수 없다고 할 때**
   * **원인**: 시험장의 scikit-learn 버전이 너무 낮아서 해당 최신 알고리즘을 지원하지 않는 경우입니다.
   * **해결**: 구형 알고리즘인 `GradientBoostingClassifier`로 우회해야 합니다. 아래 코드를 참고하세요.
   ```python
   from sklearn.ensemble import GradientBoostingClassifier
   
   final_model = GradientBoostingClassifier(
       learning_rate=0.15, max_depth=5, random_state=42
   )
   # 구형 알고리즘은 class_weight 옵션이 없으므로, 학습할 때 샘플 가중치를 직접 줍니다.
   sample_weights = np.where(y == 1, 7, 1) 
   final_model.fit(X_selected, y, sample_weight=sample_weights)
   ```

4. **점수가 0.97점 아래로 생각보다 안 나올 때**
   * 이번 데이터셋의 핵심은 **"클래스 불균형 해결"**에 있습니다.
   * `class_weight={0: 1, 1: 7}` 부분의 가중치 숫자를 **5, 8, 10** 등으로 조금씩 변경해보며 점수가 더 오르는 구간이 있는지 확인해 보세요.

5. **갑자기 피처명(컬럼명)이 변경되어 출제된 경우**
   * **대응**: 본 코드의 구조상 피처 중요도(Feature Importance)를 계산하여 상위 8개의 피처를 **동적(자동)**으로 추출(`importance_df["Feature"].head(8).tolist()`)하도록 설계되어 있습니다. 
   * 즉, 데이터의 피처명이 `feat_1`에서 `col_1`이나 `X_1` 등으로 **완전히 바뀌더라도 코드 수정 없이 자동으로 새로운 이름들을 찾아 적용**되니 안심하고 그대로 실행하시면 됩니다! (단, 제공받은 `train.csv`와 `test.csv`의 피처명이 서로 동일하게만 매칭되면 됩니다.)
